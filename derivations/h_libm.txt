# H-libm: the hypothesis on libm 0.2.16 (the version Cargo.lock pins) that the round-off proofs
# take, one constant per function and domain (plans/18 Ф28.J; docs/verification.md §1.1):
#
#   |r - f(x)| <= constant * ulp(f(x)) for every double x of the domain,
#   r libm's answer, f the true function, ulp(y) = 2^(max(floor(log2 |y|), -1022) - 52).
#
# A measurement is a tested hypothesis, not a proof. `measured` is the largest error that
# libm_hypothesis_arb.c finds in Arb balls; PARI/GP at 600 digits recomputes each row's worst
# input and agrees (libm_hypothesis.gp). `constant` is `measured` rounded up to the next 1/64 ulp,
# and 1/2 for sqrt and cbrt, which are correctly rounded (sqrt is the IEEE `sqrtsd` on x86_64,
# cbrt is CORE-MATH's). verify.sh §9 fails if any point is above its row's constant, and if
# `measured` is not what the run finds. A larger error may exist where no point falls. The
# published largest known errors (Gladman et al., August 2026) are among the points, so for
# atan2, hypot, tan, sin, cos, exp, acos, asin and atan the row's worst is a published input.
#
# A result that rests on a constant here says "under H-libm".
#
